## 25 September 2026: QNA route review

The [ONS search API documentation](https://developer.ons.gov.uk/retirement/v0api/) distinguishes search metadata from observation-bearing data endpoints. Metadata queries for ABMI under PN2 and QNA returned separate entries with the same seasonally adjusted chained-volume GDP title. The QNA entry identifies `/economy/grossdomesticproductgdp/timeseries/abmi/qna`. D-016 corrects the earlier PN2 retrieval link while retaining the fixed QNA-before-registration rule.

The [QNA archive index](https://www.ons.gov.uk/economy/grossdomesticproductgdp/timeseries/abmi/qna/previous) was opened without following data downloads. It lists versioned CSV/XLS links and explicitly labels older rows by **date superseded**. For example, the row labelled 30 June 2026 points to `/generator?format=csv&uri=/economy/grossdomesticproductgdp/timeseries/abmi/qna/previous/v43`; the 31 March 2026 row points to `previous/v42`. These are observed link identities, not verified file contents or original publication dates. No download body or file availability check was performed. The current latest link has no version suffix and does not itself establish a frozen vintage.

The [QNA January-March 2026 release-calendar record](https://www.ons.gov.uk/releases/gdpquarterlynationalaccountsukjanuarytomarch2026) records release on 30 June 2026 at 07:00 UK local time; its search metadata gives 06:00 UTC. This is publication metadata, not a selection of the final H1 vintage. The registration timestamp does not yet exist. Series search dates alone do not supply the publication time; the calendar record is required. The archive also advertises a latest version dated 30 June; it is incorrect to assign the `v43` supersession label to that release automatically.

The metadata route is identified. **The eligible release, exact version-to-release association, selected-file availability and content are not yet verified.** Once the actual public registration timestamp exists, identify the eligible completed QNA release, establish the exact version association and stop if it cannot be established without inspecting observations. Apply the registered stop-and-amend rule rather than substituting a mutable latest download. Only after G1 and G2 permit acquisition may the selected file be downloaded, hashed and checked for all 260 required levels.

This review inspected metadata and archive links only. It did not acquire GDP values, unemployment values or a real-time vintage dataset. The existing literature/headline exposure record remains unchanged.
