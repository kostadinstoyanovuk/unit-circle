## 4. Rolling estimator and indicator

At each growth position t≥W−1, take exactly the W observations `g[t-W+1],…,g[t]`. Fit by ordinary least squares

`g[s] = c + phi1*g[s-1] + phi2*g[s-2] + error[s]`

using only the last W−2 observations as responses and that same window's first two values only as lags. Include an intercept. Each window is fitted independently; no preceding observations enter its design matrix. The primary W is **40**, so the first fitted indicator is at t=39 and each fit has 38 regression rows. The fitting criterion is unweighted sum of squared residuals. For numerical conditioning, center each lag column, divide by its root mean square centered magnitude, solve the two-column least-squares problem with NumPy `lstsq(rcond=None)`, undo that scaling and recover the intercept from response and lag means. Require rank two and finite coefficients/residuals; a zero scale or failed solve is a failure, not a reason to drop a window.

The two companion roots solve `lambda^2 - phi1*lambda - phi2 = 0`; they are not the reciprocal lag-polynomial roots. Set `M(t)=max(abs(lambda1),abs(lambda2))`. For discriminant `D=phi1^2+4*phi2<0`, `M=sqrt(-phi2)`. For D≥0, compute the larger-magnitude real root as `(phi1+copysign(sqrt(D),phi1))/2` and the other by the root product `-phi2` divided by that root; when both vanish use zero. Retain rolling estimates outside the stationary region. Do not clip or project coefficients or M to the unit circle. All pre-warm-up positions are unavailable; later nonfinite or unidentified windows fail the affected analysis rather than being treated as warm-up or silently excluded.

## 5. Recession episodes, eligibility and primary statistic

A qualifying recession run consists of **two or more consecutive quarters with g[t]<0**. Zero or positive growth interrupts a run. A terminal run of two or more negatives counts; a terminal singleton does not. Its onset is the first quarter and its end is the last quarter, both inclusive.

Process qualifying runs chronologically. If a new run's onset minus the preceding qualifying run's inclusive end is **≤8 positions**, merge it into that episode. Retain only the first onset and extend the episode end to the new qualifying run's end. Apply this iteratively, allowing chained merges. Isolated negative quarters do not reset the merging clock. Perform merging before eligibility; a merged episode with an ineligible first onset remains ineligible even if a later run would qualify separately.

For each episode onset r, define `Delta[r]=M(r-1)-M(r-9)`. It is eligible only if M(r−9) exists, so the earliest eligible zero-based onset is W+8: **48** for W=40, 40 for W=32 and 56 for W=48. All required later moduli must also be finite. Both windows end before the onset: for W=40 their supports are r−48,…,r−9 and r−40,…,r−1, sharing 32 observations. Earlier recessions may fall in these windows.

Let m be the number of eligible episodes and `S=sum(Delta[r])/m`. Retain all signs; no trimming, weighting or selection by magnitude is allowed. Record all qualifying runs, merged episodes, eligible/ineligible onsets, each signed Delta, m, S and `k=count(Delta>0)`. k is descriptive, not a count of individually significant warnings. If m=0, return not estimable with S and p absent and no null fit or surrogate draws; do not substitute zero.

## 6. Fitted null, surrogate draws and primary p-value

For an estimable observed statistic, fit the same intercept-inclusive OLS AR(2) once to all 259 growth observations, using 257 conditional regression rows. Require finite, identifiable estimates and **strict stability**: `phi1+phi2<1`, `phi2-phi1<1`, `phi2>-1`, and a finite computed M<1. A boundary fit, unstable fit or disagreement between these numerical stability checks fails the comparison before any draws. Do not project the fitted null. This requirement applies to the full-sample generating fit, while rolling fits remain unconstrained.

Calculate its 257 ordered conditional residuals and subtract their arithmetic mean explicitly. Do not standardize them or apply a degrees-of-freedom variance correction. Hold the fitted intercept and coefficients fixed during generation. Every surrogate begins with the same two observed growth values g[0],g[1]; there is no burn-in or stationary initialization of these fitted-null surrogates.

For each of exactly **B=1,000 attempted** primary draws, sample 257 residual indices independently with replacement using one `integers(0,257,size=257)` call. Recursively generate positions 2,…,258 with the fitted intercept/coefficients and the selected centered residuals in draw order. Refit every rolling window, detect its own negative runs, merge them, apply primary eligibility and calculate its own S_b. The primary therefore repeats the endogenous recession selection rule in every surrogate.

Drop and count a draw only when it has no eligible episode. Never replace it. Record numerical, generation, fit and undefined-statistic failures separately; continue the remaining attempted draws for accounting and invalidate that comparison's p-value if any such failure occurs. Do not retain a partial statistic from a failed draw. The identity is `attempted = retained + no_eligible + failed`. Store requested, attempted and retained counts separately. The retained distribution is conditional on having eligible episodes.

With finite observed S, **B′>0 retained** draws and no failures, let `K=count(S_b>=S)`, counting ties. Report `p=(1+K)/(B′+1)`. If B′=0, report p as undefined. With observed no-episode or an unusable fitted null, attempted draws are zero. Save the full retained distribution and the status of every numbered attempt. Do not restart with a new seed or increase B after seeing the output. DR-1 rejects this specified upper-tail comparison when **p≤0.05**.

Report B′, K and the grid spacing `1/(B′+1)`. For simulation precision, report `q=K/B′` and a 95% Wilson interval for the conditional exceedance probability, using z=1.959963984540054: center `(q+z²/(2B′))/(1+z²/B′)` and half-width `z*sqrt(q*(1-q)/B′+z²/(4B′²))/(1+z²/B′)`. This describes random-surrogate precision, not a confidence interval for an economic effect. The plus-one convention and Wilson calculation do not prove exact finite-sample validity of the fitted-null procedure.

## 7. Episode interval and all registered secondary analyses

The primary episode interval resamples the m observed eligible Delta values with replacement. Make exactly **10,000** resamples of m indices, in one `integers(0,m,size=(10000,m))` call from its independent stream; average each row. Report the 5th and 95th percentiles of those means using NumPy's **linear** quantile convention. Save the means and generator states. With m=0, no interval and no draws; with m=1, report the degenerate interval and flag it. This is a conditional episode-resampling diagnostic: few episodes and overlapping estimation windows limit interpretation. It is not asserted to have calibrated coverage for selected historical episodes.

Report every following analysis in one table even when it disagrees with H1. Each surrogate comparison requests 1,000 attempts and uses the same upper-tail formula and failure accounting; none replaces the primary or selects a preferred window.

| Analysis | Exact specification |
|---|---|
| W=32 and W=48 | Repeat the complete primary procedure separately, including window-specific observed/surrogate eligibility, with independent surrogate streams |
| Fixed observed dates | W=40; use the observed eligible primary onset positions unchanged in every surrogate; do not detect surrogate recessions; retain the identical Delta endpoints |
| Wild signs | W=40, endogenous onsets; keep the centered full-sample residuals in their original order, multiply each by an independent equiprobable sign, and use the same recursion; one `integers(0,2,size=257)` call per draw, mapping 0 to −1 and 1 to +1 |
| Kendall trend | At each eligible episode calculate tau-b between positions 0,…,15 and M(r−16),…,M(r−1); average episode tau-b values. Require M(r−16) to exist, so W=40 first eligibility is onset 55. Use tau-b's tie denominator, not an asymptotic Kendall p-value. A constant segment is an undefined-statistic failure |
| Lag-one comparator | For each W=40 growth window, subtract its own mean and calculate `A(t)=sum(v[1:]*v[:-1])/sum(v*v)` with all W centered values in the denominator and no W/(W−1) correction. Negative values are valid; zero denominator fails. Form A(r−1)−A(r−9), average using primary episode/eligibility rules and report its own upper-tail p |

For clarity, with ordered positions distinct, the tau-b numerator is concordant minus discordant pair count; its denominator is `sqrt(120*(120-T))`, where T counts tied-modulus pairs among the 16 values. T=120 makes it undefined. Ties are equality of the stored numerical values; no rounding tolerance is introduced.

The **same 1,000 primary residual-surrogate paths** supply the primary, Kendall and lag-one comparisons. Episode detection is repeated on each generated path. Eligibility, retention, exceedances and denominator are calculated separately for each statistic; in particular Kendall cannot inherit primary B′. A failure unique to a statistic invalidates that statistic only, while generation failure invalidates all affected comparisons. The wild scheme preserves the ordered residual magnitudes, not every possible feature of changing volatility. Secondary raw p-values are reported as prespecified sensitivity evidence without a new primary conclusion or an omnibus multiplicity claim.

### H1 size/power generating mechanism and initialization

Every generated series has 259 observations. The base recursion has `a=0.3`, `b=0.1`, `c=1.5`, stationary mean `mu=c/(1-a-b)=2.5` and independent Gaussian innovations with mean zero and standard deviation **3.5**. The base roots are 0.5 and −0.2. There is **no burn-in**.

Draw the initial pair from the base stationary bivariate Gaussian. Its marginal variance and lag-one covariance solve the stationary covariance equations:

`v = 3.5²*(1-b)/((1+b)*((1-b)²-a²)) = 1225/88`,

`h = a*v/(1-b) = v/3`.

Consume one `standard_normal(2)` call yielding z0,z1, and set `x[0]=mu+sqrt(v)*z0`, `x[1]=mu+(h/sqrt(v))*z0+sqrt(v-h*h/v)*z1`. Then draw the remaining innovations in one `normal(0,3.5,size=257)` call and recursively generate x[2],…,x[258] in order. The initial pair is newly drawn once for each generated series and held fixed for all of that series' fitted-null surrogate runs. The fitted surrogate null is estimated from that generated series using section 6, including its observed first pair and empirical centered residuals; it does not use the known generating coefficients or Gaussian innovations directly.

### Four power cells: AT-16

For each valid cell j, report `p_j=R_j/200`, `meanS_j=sum(S_i)/200`, rejection-rate Monte Carlo standard error `sqrt(p_j*(1-p_j)/200)`, the Wilson interval from section 6 with denominator 200, and the sample-standard-deviation of S (variance denominator 199) divided by sqrt(200) for meanS precision. To operationalize the original AT-16 phrase “rising with kappa up to Monte Carlo error,” report every adjacent power difference and its estimated standard error `sqrt(p_j*(1-p_j)/200+p_(j-1)*(1-p_(j-1))/200)`. **D80 uses the first raw crossing.** If any of the four cells is invalid/incomplete, D80 is undefined. Otherwise inspect cells in increasing kappa order and choose the smallest j with `p_j≥0.80`. If there is no crossing at kappa≤1.6, D80 is undefined. If j=0, use kappa80=1.0 and D80=meanS_0. Otherwise the previous raw rate is below 0.80 by construction. Report the two cells and weight. D80 is a Monte Carlo point diagnostic with cell-level uncertainty shown, not a claimed confidence bound or an economically defined minimum important effect.
