## 1. Title

*Did UK recessions give warning when the AR(2) parameters are allowed to drift? A registered extension (E3) with a time-varying AR(2) and filtered root moduli, 1955–2019.*

## 2. Question and hypothesis

H1 measures persistence with a 40-quarter rolling window. E3 lets the AR(2) coefficients evolve as random walks and reads M(t) from the Kalman-filtered coefficients. It asks whether, before UK recession onsets from 1967Q2 to 2019Q4, the filtered M(t) rose more than the registered constant-parameter AR(2) surrogate procedure would produce, when the same time-varying estimator is applied to each surrogate.

**Hypothesis E3 (one-sided).** S (§8) is unusually large relative to the §9 surrogate distribution. The alternative is upper-tailed, and there is one confirmatory comparison. The interpretation limits of H1 §10 apply.

**Disclosed limit.** The variances (σ², q1, q2) are estimated from the whole sample. The filtered M(t) uses only data up to t *given those variances*. It is not an entirely real-time procedure (research-repo `audit/SPECIFICATION_AUDIT.md`, line 33).

## 3. Prior work and difference

1. The registered H1 background (H1 §2) applies unchanged.
2. E3 differs from H1 only in how M(t) is estimated: a random-walk-coefficient AR(2) by Kalman filter instead of a rolling window. The state-space methods are standard textbook material (Durbin and Koopman 2012, chapters 2–5 and 7, as listed in plan p. 7). They were not re-read for this addendum, and no page-level claim is made.
3. The Paper I literature search (plan §11) had not been completed at registration. No claim of difference from unsearched work and no claim of novelty is made.

## 5. Variables

g as H1 §3: **259** growth observations at positions 0,…,258 (1955Q2–2019Q4).

## 6. Model and indicator

**State-space form.** For positions s = 2,…,258 (257 observations), with `z[s] = (1, g[s-1], g[s-2])'`:

- observation: `g[s] = z[s]' alpha[s] + eps[s]`, with `eps[s] ~ N(0, sigma2)`;
- transition: `alpha[s+1] = alpha[s] + eta[s]`, with `eta[s] ~ N(0, sigma2 * diag(0, r1, r2))`;
- initial state: `alpha[2] ~ N(0, sigma2 * 1e8 * I3)`, an approximate diffuse start as in AT-11 (P0 = 10⁸ I);
- ε and η are independent;
- the plan's q1 and q2 are `q1 = sigma2*r1` and `q2 = sigma2*r2`. The intercept c is constant because its state variance is 0.

**Likelihood (prediction-error decomposition, σ² concentrated out).**

1. Run the Kalman filter with σ² = 1 for the given (r1, r2). This gives one-step prediction errors v[s] and scaled variances F[s].
2. Exclude the first **d = 3** terms (s = 2, 3, 4), one per diffuse state element, leaving n* = **254**.
3. Set `sigma2_hat(r) = (1/254) * sum_{s=5..258} v[s]^2 / F[s]`.
4. The concentrated log-likelihood is `l(r) = -(254/2)*(ln(2*pi) + 1 + ln(sigma2_hat)) - (1/2)*sum_{s=5..258} ln F[s]`.
5. Report the implied σ̂², q̂1 = σ̂²·r̂1 and q̂2 = σ̂²·r̂2.

**Filter implementation.**

- Use the square-root (array) covariance filter of research-repo `uc_core.statespace.kalman_filter`, version 2, which passed AT-11 (D-019, at commit `6f9400e`).
- A batched or re-implemented filter may be used only if, on every X.3 fixture of §11 and on AT-11's fixture, it agrees with that reference to **1e−8** in every filtered state and **1e−6** in l(r).
- A non-positive or non-finite F[s], or a non-finite state, is a **failure**.

**Maximisation.** Deterministic, and identical for the observed series and every surrogate:

1. **Grid.** Evaluate l on the 16 × 16 grid with r1, r2 ∈ {0} ∪ {10^(k/2): k = −16, −15, …, −2}, that is 0, 1e−8, 10^−7.5, …, 1e−1. Non-finite grid values are discarded. If all 256 are non-finite, the fit fails. Take the maximum, breaking ties by the smaller r1 + r2 and then the smaller r1.
2. **Refinement.** Coordinates of the grid maximum that are strictly positive are refined in log10 scale, with bounds [−10, 0], by SciPy `minimize(method="L-BFGS-B")` on −l. Use the default tolerances and finite-difference gradient, `maxiter=200`, starting at the grid point. A coordinate equal to 0 at the grid maximum is held at 0.
3. **Acceptance.** Accept the refined point if l is finite there and at least the grid maximum. Otherwise keep the grid maximum.
4. **Record.** The grid maximum, the refined point, the optimiser status and whether each r̂ lies at 0 or at the upper bound 1. A boundary estimate is valid, not a failure.

**Indicator.** Run the filter once more at (σ̂², r̂1, r̂2).

- For every position t, take the **filtered** state `a(t|t) = (c_t, phi1_t, phi2_t)`, which conditions on g[0],…,g[t].
- M(t) is H1's companion-root modulus (H1 §4 formulas) of (phi1_t, phi2_t).
- **M(t) exists for t ≥ 39**, a warm-up of 40 growth observations matching H1's W = 40. Earlier filtered states are computed but not used.
- Smoothed states are not used.
- Nothing is clipped or projected.

## 7. Recessions

H1 §5 applies word for word to g:

- two or more consecutive negative quarters;
- merge when onset − previous end ≤ 8;
- merge before eligibility;
- an episode is eligible if M(r−9) exists, so the earliest onset is position **48** (1967Q2) and the eligible set is H1's.

Onsets from 2020 on are outside the sample, as in H1.

## 8. Statistic

`Delta[r] = M(r-1) - M(r-9)`, S = the mean over the m eligible episodes, and k = count(Delta > 0), all as H1 §5 with the §6 filtered M(t). If m = 0, the result is not estimable.

## 9. Null and p-value

**Fitted null.** Exactly H1 §6:

- the intercept-inclusive OLS AR(2) on all 259 observations;
- strict stability required, with no projection;
- 257 centred residuals;
- B = **1,000 attempted** draws, one `integers(0,257,size=257)` call each;
- recursion from the observed g[0], g[1].

**Per surrogate (primary).**

1. Re-estimate (σ², r1, r2) on the surrogate by the complete §6 procedure: grid, refinement, acceptance.
2. Filter.
3. Compute the filtered M(t) for t ≥ 39.
4. Detect the surrogate's own negative runs, merge them, apply eligibility and compute S_b (endogenous onsets).

Drop and count draws with no eligible episode. A fit or filter failure in any draw is recorded and invalidates the comparison's p, as in H1 §6. Compute p = (1+K)/(B′+1), K, B′, q and the Wilson interval as in H1 §6.

**Decision rule DR-E3.** Reject when the **Holm-adjusted p ≤ 0.05** (§10). Report the raw p at freeze, labelled "raw, not family-adjusted".

**Random numbers.** As H1 §8, with master seed **1927** and the streams in Annex A. The optimiser and filter consume no random numbers.

- For h members, order the inputs increasingly, breaking ties by extension number. The adjusted value at rank i is `min(1, max_{j≤i}((h−j+1)·p_(j)))`.

## 11. Outcome rule and the X.3 synthetic design

**Outcome.** As H1 §10, with the Holm-adjusted p in place of the raw p: adjusted p ≤ 0.05 gives the "unusually large" statement with S, every Delta, k/m and raw and adjusted p; adjusted p > 0.05 is inconclusive, with the Branch B diagnostic reported as a labelled diagnostic; an undefined p or failure is not estimable or failed. The reference is "fitted constant-AR(2) surrogate procedure with a re-estimated time-varying AR(2)".

**X.3 synthetic design.** These are the AT-15 and AT-16 checks adapted to E3. They are run after registration and before any E3 computation on UK data, without tuning. None has been run.

**Prerequisites.**

- F2 (plan p. 7) and AT-11 on the implementation used.
- With r1 = r2 = 0 and the §6 prior, the final filtered state equals the full-sample OLS estimate to 1e−6 on one base synthetic series, generated from stream 5320, cell 1, replicate 0.
- The §6 agreement test for any batched filter.

**Generating processes.** H1 §9 exactly:

- 259 observations, a = 0.3, b = 0.1, c = 1.5, innovation s.d. 3.5;
- stationary Gaussian initial pair (v = 1225/88, h = v/3);
- no burn-in;
- one `standard_normal(2)` and one `normal(0,3.5,size=257)` call per series.

**Size (AT-15 adapted).**

- 200 base series from stream 5320 (cell 0, replicates 0–199), surrogates from stream 5321.
- Each is analysed in the E3 primary mode: §6 ML fit, filtered M, endogenous onsets, and 1,000 constant-AR(2) surrogates, each re-estimated.
- Pass: rejection rate between **0.02 and 0.09** inclusive, with all 200 valid.

**Power (AT-16 adapted).**

- κ ∈ {1.0, 1.2, 1.4, 1.6}, **200** series each. Generation uses stream 5330 (cells 0–3); fixed-onset surrogates use stream 5331.
- H1's imposed onsets at zero-based positions **49, 99, 149, 199, 249**, with the planted `(kappa*0.3, kappa^2*0.1)` coefficients and mean-preserving intercept in the eight positions before each (H1 §9).
- Compute S at those positions from the filtered M, with fixed-date surrogates, each re-estimated.

**Reporting and D80.** As H1 §9, including the 1.96-SE decrease flag and the first-raw-crossing D80.

**Computational note (unverified estimate).**

- The size and power cells need about 1,000 × 1,001 maximum-likelihood fits in total.
- A per-series Python filter loop is expected to be too slow for this. A filter vectorised over surrogates, validated by the §6 agreement test, is expected to be needed.
- Run time is not a reason to reduce B, the number of series or the grid after registration.
